Session Editor

Build the operating recipe step by step: Add step, pick a command, set parameters, and add remarks. Import JSON loads steps into the editor only (nothing is written until Save). Import again to append or combine workflows. Load replaces the editor from a file on disk. Delete permanently removes the selected workflow file. Reset clears the editor without touching disk files. The simulator runs against the live STS database — switch lists are generated at each Generate Switch Lists step.

Simulator

Check one or more Sections to preview and run (from section labels in the recipe). Start / Stop / Skip use the same recipe step numbers shown in the step list (S marks a section header only — e.g. S8 is still step 8). Gaps fill Skip steps (editable, e.g. 1-2,5,8-10); skipping every step in a section unchecks it. Use simulator Repeat to run the selection multiple times. Switch-list format is set on each Generate Switch Lists step. DB session: —. View output in Sessions after a run.
