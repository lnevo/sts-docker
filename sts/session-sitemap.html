Operating Session Browser

Layout-owner navigation for browsing generated switch lists and waybills by operating session. Links below use the current DB session when available. Generated HTML is served through so.php so temp/ never appears in URLs.

Session Browser Trains & Switch Lists Waybills
Entry points
  • Session overview session_overview.php?session=N — default session page: trains & consolidated views
  • All-session totals session.php — session picker + cumulative statistics across sessions
  • Session Editor editor.html — workflow builder & simulator
Session panel (quick links)
  • Session overview
  • Print all switch lists session_N/print_all.html — all trains, all phases
  • All waybills session_N/waybills/index.html
  • Print all waybills session_N/waybills/print_all.html
Browse limits
  • Only sessions 1 through the current DB session appear in pickers
  • Session 0 is excluded from browsing
 Per train (interactive)
  • Train view job.php?session=N&job=JOB — embedded switch list, phase nav, style picker
  • Prev / next session (same train) — on the train view page
  • Train switch list index phase_PP/JOB/index.html — work-leg links to job.php
Individual switch lists (generated)
  • Switch list page phase_PP/JOB/phase_LL_STYLE.html — mobile, half, full, dmp, wo, x2010
  • Embedded in job.php iframe (&embed=1 strips nav)
  • Style dropdown on job.php and on generated switch list pages
Print switch lists
  • Print all (one train) phase_PP/JOB/print_all.html
  • Print all (session) session_N/print_all.html
Session scope
  • Waybill index session_N/waybills/index.html — prev/next session nav
  • Print all waybills
  • Single waybill session_N/waybills/{waybill}.html — frozen snapshot
Train scope
  • Job waybill index waybills/job_JOB.index.html
  • Print all (job)
  • Linked from job.php header — All waybills
Phase + train scope
  • Phase waybill index waybills/phase_PP_JOB.index.html
  • Print all (phase + train)
  • Waybills on job.php match cars on the active switch list
Navigation flow
Typical path

Session overview → Train view → switch list (embedded or open) + waybills for that phase. The overview links out to All-session totals.

Header links (most session pages)
  • STS Main Menu → /sts/index.html
  • Session N → session_overview.php?session=N (back to the overview)
  • All-session totals (on the overview) → session.php?session=N
  • All waybills → session or job-scoped waybill index
  • All switch lists (job.php) → that train’s switch list index
