Operating Session Browser

Browse generated switch lists and waybills by operating session. Links use the current DB session when available; generated HTML is served through so.php. Requests for a session beyond the current one redirect to the latest overview.

Navigation
Typical path

Session overview → click a train → train switch lists → use the Train / Style dropdowns or the Waybills link (scope follows the selected train). Switch-list and waybill bundles cross-link to each other.

Header links
  • STS Main Menu, Session N, and Site Map (top-right) on session pages
  • Print bundles carry a minimal nav (Main Menu, Session N, Waybills/Switch lists) plus the Train / Style dropdowns top-right
  • Session-wide switch lists & waybills are reached from the session overview or the Train dropdown's "All"
  • Prev / next session buttons on every print bundle (built on demand)
